# Square Domination (Unity/C#)

Square Domination is a lightweight 2D strategy game built in Unity using C# and object-oriented gameplay architecture. 
Players compete to capture territory on a grid-based map by expanding, defending, and reacting to randomly generated enemy movement. 
The game emphasizes simple mechanics combined with real-time state control, modular scripts, collision logic, and performance-safe updates.

### Features
- Fast, grid-based territory capture mechanics
- Lightweight C# architecture with modular gameplay scripts
- Deterministic enemy behavior with state-based control
- Optimized collision checks and update loops for smooth performance
